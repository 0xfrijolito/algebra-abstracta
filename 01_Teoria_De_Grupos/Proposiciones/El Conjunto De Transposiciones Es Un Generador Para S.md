## Proposición
El conjunto de las transposiciones es un conjunto de generadores para $S_{n}$.

De hecho se puede probar que las transposiciones $a_{k} = (k\;\; k+1)$ con $1 \leq k \leq n − 1$ son un conjunto de generadores de $S_{n}$.
## Demostración
Sea $S_{n}$ el grupo de permutaciones y sea $H$ definido por
$$
H = \{(k \;\; k+1) \mid k = 1, 2, ..., n-1 \}
$$
Todas las transposiciones del grupo $S_n$. Luego podemos probar que $S_{n} = \left<H\right>$. Usando la proposición [[Cada permutación Tiene Expresión De Transposiciones]] entonces cualquier elemento de $S_{n}$ puede ser expresado como una combinación de elementos de $H$. 

Q.E.D
