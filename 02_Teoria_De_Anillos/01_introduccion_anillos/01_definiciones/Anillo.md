## Definición
Un anillo $R$ es un conjunto junto a dos operaciones binarias $+$ y $\times$, llamadas adicción y multiplicación respectivamente, que cumplen los siguientes axiomas.
1. $(R, +)$ Es un grupo abeliano.
2. $\times$ es asociativa: $(a \times b) \times c = a \times (b \times c)$ para todo $a,b,c \in R$.
3. Las dos operaciones se relacionan con la ley distributiva, para todo $a,b,c \in R$ $$(a + b) \times c = (a \times c) + (b \times c)$$
Se dice que $R$ es un anillo conmutativo si la multiplicación es una operación conmutativa. Se dice que el anillo $R$ tiene una identidad si existe un elemento $1 \in R$.
